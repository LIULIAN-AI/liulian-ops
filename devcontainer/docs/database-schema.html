④ 常见问题

为什么有 65 张表，但只有 11 张有数据？

Spring Boot JPA 的 spring.jpa.hibernate.ddl-auto=update 会扫描所有 Java @Entity 类自动建表 — 包括早期实体（bank、funding、ffunding 等历史遗留）、关联中间表（company_tag_news_tag 是多对多桥接）、用户互动表（user_* 系列业务还未启用）。 只有 11 张通过 import_data/import_scripts/*.py 灌过 CSV 数据，其余等业务流程触发或后续批次。

为什么有 4 个营销表？

marketing 是营销活动主表（154 行），marketing_base_header 存基础信息（200 应用），marketing_app_latest_record 跟踪 App 最新版本（122 记录），marketing_social_media_detail 存社交媒体明细（921 条）。 它们都用 marketing_sort_id 关联同一个营销活动，是 1-N 拆分。

staff_management vs management_team_staff 区别？

staff_management 是 新版结构（2,740 行 — 实际使用），management_team_staff 是旧版遗留实体（0 行）。代码可能两者都引用 — 看 import 脚本，新版统一往 staff_management 写。建议查 Java repo 哪些 Service 还在用旧表，渐进迁移。

怎么连数据库？

命令行：docker exec -it my-ubuntu-dev mysql -uroot -proot neobanker
phpMyAdmin GUI：http://127.0.0.1:8088，账号 root / root（已配置好）
